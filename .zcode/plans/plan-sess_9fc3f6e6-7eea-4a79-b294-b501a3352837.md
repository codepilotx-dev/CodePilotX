### Step 1: Add `summarizeProcessItems` utility
**File:** `apps/desktop/renderer/src/features/session/timeline/summarizeProcessItems.ts` (NEW)

Pure function that takes `processItems: Item[]`, `turnStatus: TurnStatus`, `elapsedSeconds: number` and returns `{ active, failed, label }`:

- **Failed items** → `{ active: false, failed: true, label: '执行出错' }`
- **Waiting-for-permission/question/plan-confirmation** → `{ active: true, label: '等待操作' }`
- **Any streaming/running/pending items** → `{ active: true, label: '正在思考' }`
- **All completed** → format elapsed time as `执行了 X 分 Y 秒`; if no elapsed, `N 项活动`. Collapsible.
