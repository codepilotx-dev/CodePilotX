## 计划：恢复对话轮次导航条

### 目标
在桌面对话页左侧 `session-timeline-wrapper` 内添加绝对定位的轮次导航条，每个条代表一个用户轮次。点击条跳到对应的用户消息，hover 显示摘要卡片。

### 修改范围

**新建文件：**
- `apps/desktop/src/renderer/features/session/ConversationTurnNavRail.tsx` — 轮次导航条组件

**修改文件：**
- `apps/desktop/src/renderer/features/session/ConversationPage.tsx` — 添加 `deriveConversationTurnNavItems()` 纯函数，渲染 `<ConversationTurnNavRail>`
- `apps/desktop/src/renderer/styles/features/timeline.css` — 导航条和预览卡片样式
- `apps/desktop/src/renderer/features/session/ConversationPage.test.ts` — 测试纯函数

### 设计

#### 1. 数据模型 (ConversationPage.tsx)

```typescript
export type ConversationTurnNavItem = {
  id: string                    // 唯一标识（用户事件 id）
  rowIndex: number              // phaseItems 中的索引（同时也是 VList 索引）
  userText: string              // 用户消息文本
  assistantText: string | null  // 本轮最后一条 AI 回复文本
  files: string[]               // turnScoped 修改的文件路径
}
```

#### 2. 推导函数 (ConversationPage.tsx)

`deriveConversationTurnNavItems(phaseItems: PhaseTimelineItem[]): ConversationTurnNavItem[]`

逻辑：
- 逐项扫描 `phaseItems`
- 遇到 `type === 'message' && role === 'user'` 时开始一轮
- 同轮内扫描后续项直到下一用户消息：
  - `TimelineItem` 类型 — 直接判断：`assistant` 消息更新 `assistantText`，`file_patch`（`metadata.turnScoped`）收集文件
  - `ExecutionPhaseGroup` — 递归遍历其 `.items`，同上逻辑收集
- 记录 `rowIndex` 为用户消息在 `phaseItems` 中的位置
- 文件展示：取 `filePath` 或 `metadata.files[].path`

#### 3. ConversationTurnNavRail 组件

- 接收 `items: ConversationTurnNavItem[]` 和 `onNavigate: (rowIndex: number) => void`
- 定位在 `.session-timeline-wrapper` 内 `position: absolute; left: 8px; top: 0; bottom: 0;`
- 每个导航条是 `<button>`，render 在 flex column 容器中
- `onClick` → `onNavigate(item.rowIndex)`
- 外层包裹 `<Tooltip>`（`side="right"`, `delayDuration=700`）

#### 4. 渲染位置 (ConversationPage.tsx)

在 JSX 中：
```tsx
<div className="session-timeline-wrapper" ...>
  <ConversationTurnNavRail
    items={navItems}
    onNavigate={(rowIndex) => {
      timelineListRef.current?.scrollToIndex(rowIndex, { align: "center" })
    }}
  />
  <SessionTimelineView ...>...</SessionTimelineView>
</div>
```

#### 5. CSS (timeline.css)

**导航条容器 (`.conversation-turn-nav-rail`)：**
- `position: absolute; left: 0; top: 0; bottom: 0; z-index: 5;`
- `width: 28px; pointer-events: none;`（为了让鼠标穿透到 timeline，但子元素设 `pointer-events: auto`）
- Flex column, 分散对齐（间距参照 `--layout-section-gap`）

**导航条 (`.conversation-turn-nav-item`)：**
- `button` reset，`cursor: pointer; display: block;`
- 默认：`width: 3px; height: 20px; border-radius: 2px; background: var(--c-border-soft);`
- Hover/focus-visible：`width: 4px; height: 32px; background: var(--c-text-meta); transition: all 150ms`
- 当前激活：使用 `var(--c-accent)` 颜色（若当前轮次可见）

**预览卡片 (`.conversation-turn-preview-card`)：**
- 基于 `.tooltip-content` 扩展，追加 `min-width: 220px; max-width: 300px; padding: 10px 12px`
- 标题 `.preview-card-user-text`：`font-weight: 500; white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`
- 正文 `.preview-card-assistant-text`：`font-size: var(--fs-12); display: -webkit-box; -webkit-line-clamp: 2; -webkit-box-orient: vertical; overflow: hidden;`
- 文件区 `.preview-card-files`：单行省略，文件间 `·` 分隔

**玻璃效果 (data-glass-surfaces="on")：**
- 复用现有 `popover.css` 中对 `tooltip-content` 的 `:root[data-glass-surfaces="on"]` 规则
- 在 `timeline.css` 中只需添加 `:root[data-glass-surfaces="on"] .conversation-turn-preview-card` 覆盖需要自定义的部分

#### 6. 测试 (ConversationPage.test.ts)

添加 `deriveConversationTurnNavItems` 测试：
1. 多轮用户消息 → 生成多个导航条，`rowIndex` 正确
2. 每轮取最后 AI 回复作为 `assistantText`
3. 只收集 `turnScoped` file_patch 的路径
4. 无修改的轮次不包含文件
5. `ExecutionPhaseGroup` 嵌套不干扰轮次切分
