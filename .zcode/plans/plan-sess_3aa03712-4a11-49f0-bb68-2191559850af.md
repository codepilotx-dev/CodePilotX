## 风险与注意事项
- 生成文件（`generated/` 下 30+ 文件）由 schema 驱动，改 Rust 协议层会自动重新生成；不改生成器输入而手工改生成文件会丢失
- `codexHome` 字段改名 `codepilotxHome` 需要 Rust 协议层 `InitializeResponse` 同时发两个字段做迁移过渡
- Theme ID 改名会影响已存储的用户偏好（`localStorage`），需考虑迁移或保留旧 ID 的兼容读取
- `arg0` 安全过滤器的 `CODEX_` → `CODEPILOTX_` 改变需要仔细 review：当前过滤是为了防止 `.env` 文件篡改 `CODEX_*` 配置变量；改为 `CODEPILOTX_*` 后旧 `CODEX_*` 可从 `.env` 设置（这是兼容性需要的）
